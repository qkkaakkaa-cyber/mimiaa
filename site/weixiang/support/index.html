微响技术支持

连接电脑微信、设置 AI，或向我们反馈问题。

开始接待

  1. 打开并登录电脑微信，保持会话列表可见。
  2. 在微响检查连接状态，按 macOS 提示开启辅助功能及屏幕录制。
  3. 填写自己的 AI API 密钥并测试连接。设置助手名称、接待范围和发送方式。
  4. 点击开启微信接待。测试群聊时，在设置中填写群内完整昵称，再请对方明确 @ 你。

为什么接待没有发出回复？

查看首页的接待状态和发送方式。草稿模式需要你确认发送，你在操作微信时自动接待会暂停。再检查 AI 连接及系统权限。若微信或微响刚更新，重新打开客户端并检查连接。
