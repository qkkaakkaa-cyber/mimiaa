# 微响 · AI 接待助手

macOS 上的独立侧边助手。聊天继续在原生微信里，微响提供接待开关、业务知识、范围设置和人工待办，不复制微信收件箱。

## 已实现

- 自动读取微信辅助功能结构，发现会话列表、标题、输入框和消息区域。主流程无需选择窗口、填写联系人名称或手动标记。
- 开启后监听主列表新增或变化的会话，按队列切换并核对聊天身份。启动时会处理今天的未读，也会持续回看主列表最近 10 分钟的私聊。已经回复、无法核对消息或仍需你确认的会话不会重复发送。
- 支持私聊、群聊范围开关和会话排除名单。群聊只在新消息明确 @自己时接待。无法确定聊天类型时交给人工，不猜测类型。
- AI 使用角色、目标、业务介绍、启用问答和相关文档段落生成回复、澄清需求或转人工。支持多轮试聊，不连接微信。
- 文档支持 TXT、Markdown、文字 PDF、DOCX，每份 5MB / 8万字，最多30份。扫描 PDF 尚无文档 OCR。
- 每个会话分别保存本机文字记忆（最近40条及需求摘要，最多100段），可关闭后续记忆与调用。
- 需人工确认的回复进入待办，其他会话继续接待。打开待办会暂停自动接待，核对目标后才能确认发送。
- 发送前反复核对会话、消息指纹和输入框；已有草稿不覆盖，结果不明不自动重试。当前会话优先通过辅助功能后台输入与发送，不使用全局按键，不激活微信。检测到你实际在微信内点击、打字或滚动时自动暂停。切到其他应用后立即恢复，在微信停留约 30 秒无操作且没有手写草稿时也会恢复。程序自己的切换和发送不会触发人工暂停。需要切换会话时仍等电脑空闲，锁屏、休眠时停止。

## 使用

应用已安装在 `/Applications/回响.app`。登录电脑微信并展开会话列表，为微响开启辅助功能和屏幕录制，然后点击“开启微信接待”。开始前请在“资料”添加真实业务信息，在“设置”确定接待范围和回复模式。默认先准备草稿；切换“AI 自动接待”后才自动发送符合规则的回复。群聊仅在 @自己时触发，需填写自己的群内称呼。

微信发送快捷键需为 Enter。按 **⌘ ⇧ .** 紧急暂停，关闭助手窗口也会暂停。

## 性格与隐私

“设置”支持温和、幽默、简洁、沉稳四种性格及自定义说话要求。银行密码、验证码、登录密钥、证件号码、私人住址和其他人的聊天记录等索取会在本机拦截，不交给模型找答案。上下文中的带标签密码、长号码、手机号、邮件等做脱敏；模型也被明确要求不得提供私人资料。隐私防护不是可关闭的性格选项。

历史学习尚未连接到实际读取入口，默认不启用。当前先完成发送和接待验证，再提供独立的学习按钮、范围说明、样本数量和学习结果预览；不得宣称已读完整个微信历史。

## 助手名片与微信工具

通用版本在“设置 → 助手名片”填写 AI 对外名称和行业，在“资料”输入业务介绍、文档和常见问答。助手介绍身份时使用该名称，自动接待后也在对话记录里标注接待助手。

“微信工具”允许浏览朋友圈、保存正文草稿、进入微信编辑器，发布由本人在微信确认。指定好友动态功能默认关闭，检查可见动态后保存候选记录。当前版本点赞由本人在微信操作。

联系人画像和从私聊记录学习均默认关闭。画像在本机保存可见昵称、签名、可取得的头像及业务分类。聊天学习使用当前可见文字和微响已保存的最近消息，保留对方明确自述作为依据，无法判断的归为待确认。微信未显示的完整历史和头像不采集。

## 今日接待

首页按北京时间统计今天实际识别的新会话、私聊人数、群聊数量和已读回确认的回复条数。列表逐人显示核心事项；同一会话与消息指纹去重，不把发现的旧聊天列表算作今日来访。今日核心总结在本机汇总已有摘要。对方明确结束聊天时，闲聊 AI 可发简短收尾确认，并记录给老板看的摘要。统计保留14天。

## 睡觉代班 / 闲聊

助手首页可开关“睡觉代班 · 闲聊”，设置中可编辑开场白。每次开启代班，第一条也由真实 AI 生成，每段聊天只在首次新消息时说明“老板在睡觉，我是他的 AI 助理”，随后自然接话并适时反问。这个模式仅调用对话模型和本段会话记忆，不检索业务资料。需要老板答复的事保存在本机待办；不会捏造老板醒来时间。回来后关闭代班并查看留言。

在“记录 → 选择聊天并总结”中选联系人，微响切到该微信会话，核对会话名称并总结可见内容，不发送微信消息。

“记录”页按联系人保存每轮对话的核心、明确诉求、下一步和老板待办。摘要随接待更新，明确结束时归档；10分钟无新对话显示本轮小结。重新联系建立新一轮，保留14天、最多300轮。没有明确待办时如实留空，摘要不等于行动已执行。

## 数据与接口

业务资料、相关聊天文字和本机会话记忆在生成方案时发送到已配置的模型接口。普通截图与 OCR 在本地处理；保留的高级视觉布局接口仅在显式调用时发送窗口截图，主流程不调用。测试连接只发送固定请求。密钥使用 Electron safeStorage / macOS 钥匙串加密保存在本机；源码和安装包不内置账号密钥。一次性接口复用通过本机来源文件读取，在加密保存成功后移除导入引用文件。

工作数据位于系统应用数据目录 `workspace/workspace.json`。关闭会话记忆不删除此前数据。不要把这个目录提交到代码仓库。

## 限制

当前是 Apple Silicon macOS 本机预览版，采用本机专用的固定签名证书，签名私钥独立保存在本机构建密钥库。更新保留应用路径和证书身份；首次迁移仍需系统设置认可当前应用。未做 Apple 公证。基于微信当前版本的辅助功能标识和本地 OCR，真实私聊已验证 AI 多轮接话、实际发送和读回计数；群聊尚未完成实际连续收发验收。

只处理微信会话列表中可发现的文字消息。新消息通常会移到列表顶部；最小化、折叠、屏幕外或列表中未暴露的会话不保证发现。同一分钟内重复相同预览且未暴露未读计数的消息可能漏检。会话名称和辅助功能标识并非微信内部唯一联系人 ID；重名、类型不明或标题核对失败时不自动发送。已转文字的微信语音可接入对话；未转文字的语音会保留待办，不猜测内容。可结合聊天文字确认收到图片、视频、表情或文件。自动语音转写、附件识别、自动滚动历史、多账号并行、WhatsApp、Telegram 暂未实现。电脑需唤醒并解锁，不能用纯服务器替代本机微信。

## 开发

Node.js 22+，Xcode Command Line Tools，macOS 14+。

```sh
npm install
npm run build:native
npm test
npm run check
npm start
npm run build
npm run deploy
```

构建不会覆盖已有 dist 应用；部署验证签名并保留上一版应用，保留工作数据。自动测试使用合成界面和模型响应，不向真实微信发消息。原生纯数据自检：`native/bin/HuixiangBridge self-test </dev/null`。

AI 方案请求使用 JSON Mode 约束结构，禁止发送不完整结果；微信发送后最多五次只读回查确认气泡，期间不会重复执行发送。
